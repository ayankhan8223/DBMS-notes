Teen golden rules (poore chapter ka nichod)
  1. Input table → Output table. Output bhi table hoti hai, isliye operators ko chain kar sakte ho.
  2. Table = set of rows → duplicate rows nahi, aur order matter nahi karta.
  3. Expression ko andar se bahar (inside-out) padho — sabse andar wali bracket pehle chalti hai.
Ye operators 3 families mein bante hain

Family 1 Ek table par: σ, π, ρ
Family 2 Do same-type tables par: ∪, ∩, −
Family 3 Do tables ko jodna: ×, ⋈, outer joins, ÷

Study order

Pehle σ, π (asaan) → phir ∪ ∩ − → phir × → phir ⋈ → aakhir mein ÷. Har operator ka formula “baad mein” yaad karna hai, pehle picture dimag mein bithao.

6.1 · Big idea — Relational Algebra hai kya? start from zero

Kitchen wali analogy 🍳

Socho ek restaurant ki kitchen. Aapke paas kacchi sabzi (tables) hain. Aap chhote-chhote kaam karte ho: chhilo, kaato, milao, nikaalo. Har kaam ke baad jo aata hai wo bhi sabzi hi hota hai, to agla kaam us par kar sakte ho. Last mein dish (answer) ready.

Final answer (Table)
  • Relational Algebra (RA) = tables par kaam karne ke chhote mathematical steps ka set.
  • RA procedural hai: aap bata rahe ho “kaise” (kaunse steps, kis order mein). SQL zyada declarative hai: aap bolte ho “kya chahiye”, “kaise” database sochta hai.
  • SQL ka dimaagi engine RA hi hai — database aapki SQL query ko andar RA mein badal kar chalata hai.
Closure property — sabse important idea

Har operator ka input = relation(s) aur output = relation. Isi wajah se πName(σDept='CSE'(STUDENT)) jaisi chain ban sakti hai: σ ka output table hai → wahi π ka input ban jaata hai.

6.3 · Core 3: σ π ρ ek table par kaam karne waale operators

σ
Selection — ROWS chuno
Jo rows condition satisfy karti hain, sirf wahi rakho. Baaki hata do.

Real-life picture

Excel mein Filter laga diya: “sirf Dept = CSE dikhao”. Kuch rows gaayab, columns jaise ke taise.

Syntax

σcondition(Relation)

Condition mein: = ≠ < > ≤ ≥ aur jodne ke liye ∧ (AND), ∨ (OR), ¬ (NOT).

Pehle ye samjho — “sigma”, “pi” kya hai?

Ye bas Greek akshar hain jo naam ki jagah symbol ban gaye. Jaise “+” ka matlab jodna, waise “σ” ka matlab filter rows.

Trick

σ → Select = Slice rows (Rows → σ). Subscript mein condition hoti hai, bracket mein table.

Step-by-step: σDept='CSE'(STUDENT)

  1. Table lo: STUDENT (4 rows).
  2. Har row par condition check karo: Dept = 'CSE'?
  3. Jo true hui wo rakho (green), jo false hui wo hata do (red).
  4. Jo bachi wahi output hai — sab columns ke saath.

  • Degree same (columns nahi badalte).
  • Rows: 0 se |R| tak — kabhi zyada nahi.
  • σ ka order badal sakte ho: σc1(σc2(R)) = σc2(σc1(R)) = σc1∧c2(R)
Traps
  • σ column nahi hataata — wo π ka kaam hai.
  • σ ki condition ek row par lagti hai. “CID='C1' ∧ CID='C2'” ek hi row mein kabhi true nahi hoga! (Section 6.8 mein detail)
  • Condition mein agar NULL aaye to row select nahi hoti (6.11).

Answer: Aman (21) aur Neha (22) → 2 rows, 4 columns.

π ke rules

Size rules
  • Degree = jitne attributes likhe (yahan 1).
  • Rows ≤ original rows. Max = |R| (jab sab rows alag hon), Min = 1 (agar R khali nahi).
  • Agar key project ki, to rows kam nahi hongi (key unique hoti hai).
  • πA(πA,B(R)) = πA(R)
Traps
  • Jo column π ne hata diya, uspar baad mein σ nahi laga sakte! (agla section dekho)
  • Subscript mein comma se alag karo: πName, Dept.
  • Projection row hataata nahi (sirf duplicates ke alawa) — row filter = σ.

6.4 · Set operators: ∪ ∩ − do tables ko “set” ki tarah milana

∪ ∩ −
Union · Intersection · Difference
Do tables ke rows par set-wali maths
Pehle shart: “union-compatible”

Dono tables ke columns ki ginti same aur corresponding columns ka domain same hona chahiye. Naam alag ho sakte hain; result mein pehli table ke column names aate hain.

A ∩ B = {2,3}

Yaad rakho
  • ∪ aur ∩ : commutative + associative.
  • − : na commutative, na associative.
  • ∩ ko − se bana sakte ho: R ∩ S = R − (R − S)
  • Degree: result ka degree = R ka degree.
Traps
  • Union ke baad bhi duplicates nahi — set hai.
  • Columns ka count alag ho to union allowed hi nahi (error). Isliye aksar pehle π lagate hain taaki dono table mein sirf ek-do matching columns bachein.
  • “A mein hai par B mein nahi” → A − B. Direction galat mat kar dena.
Ab tum try karo

Q. R mein 5 rows, S mein 3 rows (union-compatible). R ∪ S ke max aur min tuples? R ∩ S ke max?

Answer: ∪ : max 8, min 5. ∩ : max 3.

6.5 · Cartesian product × aur Join ⋈ do tables ko jodna

×
Cartesian Product — sab pairs
Pehli table ki har row ko doosri table ki har row ke saath jodo.

Real-life picture

4 shirts aur 3 pants hain. Kitne outfits ban sakte hain? Har shirt × har pant = 4 × 3 = 12. Chahe wo match karein ya nahi, sab combos aate hain.

STUDENT × COURSE = har student ko har course ke saath pair karo (chahe enroll hua ho ya nahi):

C1C2C3
Rahul(R, C1)(R, C2)(R, C3)
Aman(A, C1)(A, C2)(A, C3)
Priya(P, C1)(P, C2)(P, C3)
Neha(N, C1)(N, C2)(N, C3)
4 students × 3 courses = 12 pairs
Isme Neha–C1 jaisi pairs bhi hain jo asal mein exist nahi karti. Isliye product akela kaam ka nahi — iske baad condition lagate hain (= join).
Size rules
  • Rows = |R| × |S| (exactly; koi bhi khali ho to result khali).
  • Columns = degree(R) + degree(S).
  • Example: R = 7 rows, 3 cols; S = 5 rows, 2 cols → 35 rows, 5 cols.
Traps
  • Dono mein same naam ka column (jaise ID) ho to result mein dono aate hain; naam R.ID, S.ID se alag karte hain.
  • Product bahut bada ho jaata hai — real DB mein avoid karte hain; join use karte hain.

Join ⋈ = Product + Condition (sabse important formula)

⋈
Join — sirf “meaningful” pairs
Product banao, phir sirf wo pairs rakho jo condition satisfy karti hain.
R ⋈θ S  =  σθ( R × S )

Matlab join koi nayi magic nahi — ye bas “× phir σ” ka shortcut hai. Join ke 3 roop hain:

NaamCondition kaisiOutput mein duplicate column?

Join associative aur commutative hai (natural join ke liye), isliye bracket aage-peeche kar sakte ho — result same.

Join ke size rules (GATE favourite)
  • Max = |R| × |S| (jab sab rows sab se match karein).
  • Min = 0 (koi match nahi).
  • Agar common column S ki key hai aur R ka foreign key (NULL nahi) → rows = exactly |R|.
  • Koi common column nahi → natural join = Cartesian product!
  • Same schema wali tables ka natural join = ∩.
Natural join ka trap

Natural join sab same-name columns match karta hai — chahe matlab alag ho. Agar STUDENT mein Name aur COURSE mein bhi Name hota, to ye khud-ba-khud Name = Name bhi maang leta → galat/empty result. Schema dhyaan se padho (2026 Q42 yahi trap tha!).

Semi-join (bonus, kabhi-kabhi aata hai)

R ⋉ S = R ke wo rows jinka S mein match hai (par output mein sirf R ke columns). = πattrs(R)(R ⋈ S). Jaise STUDENT ⋉ ENROLL = wo students jinke enrollments hain: Rahul, Aman, Priya.

Ab tum try karo

Q. R(A,B) mein 6 rows, S(B,C) mein 4 rows. R ⋈ S ke max aur min tuples?

Answer: Max = 6 × 4 = 24 (sab B same), Min = 0. Aur agar B, S ki key ho (aur R.B FK) → 6.

Division ka asli matlab

Ye arithmetic wala divide nahi hai. Ye ek “for ALL / har ek ko cover kiya?” check hai. Jab bhi sawaal mein “every / all / sabhi / har” dikhe → division yaad karo.

Formal definition

R(X, Y) ÷ S(Y) = T(X), jahan T mein sirf wo x hain jinke liye S ki har y ke liye (x, y) ∈ R.

  • Shart: S ke saare attributes R mein hone chahiye (S ⊂ R ke columns).
  • Result ke columns = R ke columns − S ke columns (yahan: Student).

Algebra se kaise nikalte hain — 5 steps (yahi exam mein likhna aata hai)

R ÷ S = πX(R) − πX( (πX(R) × S) − R )

Ye formula ratna mat — niche har step ko kahani ki tarah dekho. Soch: “Jo bhi candidate ek bhi required item miss kare, use nikaal do.”

  1. Candidates = πStudent(TAKES) → jin jin ne kuch bhi liya: Rahul, Aman, Priya.
  2. Sab expected pairs = Candidates × REQUIRED → agar sab ne sab required courses liye hote to ye 6 pairs hoti.
  3. Missing pairs = (Expected) − TAKES → expected mein jo actual mein nahi hai.
  4. Bad candidates = πStudent(Missing) → jinke koi pair missing hai.
  5. Answer = Candidates − Bad candidates.

Size rule (GATE trick)

Division ke Traps
  • “At least one” ≠ “all”. “Koi ek course liya” = join/select. “Sab liye” = division.
  • R − S aur R ÷ S mein confuse mat ho.
  • Divisor ke columns ka naam R ke columns se match hona chahiye, warna ÷ define nahi.
  • ÷ basic operator nahi — ye ×, π, − se bana hai (upar wala formula).
