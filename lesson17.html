17.1 · Transformation kyun? ek hi tarazu par sab ko tolo

Real-life picture

Do students: Rahul ke Maths mein 70/100, Aman ke Physics mein 30/40. Kaun behtar? Seedha 70 vs 30 compare karna galat hai, kyunki paper alag-alag scale par hain. Percentage (70%, 75%) karte hi tulna fair ho jati hai. Data normalization yahi karta hai: alag-alag units/ranges wale attributes ko ek comparable scale par laata hai.

Dusri taraf, kabhi hume exact value nahi, sirf group chahiye: "age 24" ki jagah "young adult". Ye discretization hai: continuous numbers ko bins / categories mein tod dena.

Ye "normalization" DB normal forms wala nahi hai!

Normalization (database) = table ko tod kar redundancy hatana (1NF, 2NF, BCNF...). Normalization (data transformation) = numbers ko scale karna (min-max, z-score). Naam same, kaam bilkul alag. GATE syllabus mein ye wala "data transformation such as normalization, discretization" hai.

Zaroorat dikhane wala example

Customers ko "similar" dhoondhna hai, distance (Euclidean) se. Teen customers (Age, Income):

  2. Par B ki age 60 hai aur A ki 25 — bilkul alag log. Income ke bade numbers ne age ke 35 saal ke fark ko daba diya.
  3. Min-max [0,1] lagao (age: (x−20)/40, income: (x−30000)/60000): A = (0.125, 0.333), B = (1.000, 0.367), C = (0.150, 1.000).
  4. Normalized distance: d(A,B) = √(0.875² + 0.0333²) ≈ 0.876 aur d(A,C) = √(0.025² + 0.6667²) ≈ 0.667. Ab C, B se zyada A ke paas hai, aur ye sahi lagta hai: dono ki age lagbhag barabar hai, sirf income alag.
Nateeja

Distance-based algorithms (k-NN, k-means, clustering) aur gradient-based models mein bade scale wala attribute dominate kar jata hai. Transformation se har attribute ko barabar haisiyat milti hai.

17.2 · Min-Max normalization

Notation / matlab — pehle letters samjho
  • v = ek purani (original) value, jaise marks = 50.
  • v' (v-prime) = us value ka naya normalized roop.
  • min, max = us attribute (column) ki sabse chhoti aur sabse badi value. max − min = range (phailav).
  • new_min, new_max = naye range ke dono siray (default 0 aur 1).

Chhota data {20, 40, 60, 80}: min = 20, max = 80, range = 60. Aage har example mein yahi letters aate hain.

Idea: sabse chhoti value ko 0 par, sabse badi ko 1 par rakho, baaki ko seedhi line (linear) mein beech mein.

v' = (v − min) / (max − min)

Words mein: v, min se kitna upar hai (v − min), ye poore range ka kitna hissa hai (fraction) — wahi fraction naye range mein lagao. Substitute: v = 50, min = 20, max = 80 → (50 − 20)/(80 − 20) = 30/60 = 0.5 (beech mein, jaisa hona chahiye).

Kisi bhi naye range [new_min, new_max] ke liye:

v' = new_min + (v − min)/(max − min) × (new_max − new_min)

Min-max ke traps
  • Outlier-sensitive: ek extreme value baaki sab ko 0 ke paas daba deti hai.
  • max = min (saari values same): denominator 0 → formula apply nahi hoga.
  • Naya data agar [min,max] ke bahar ho (e.g. training min–max 0–100, test value 120 → 1.2) to result [0,1] ke bahar jayega.
  • Relationships preserve hoti hain: order aur relative gap (linear map).
Ab tum try karo

Q. min = 10, max = 30, v = 25. [0,1] aur [−1,1] mein normalized value?

Answer: (25−10)/20 = 0.75. [−1,1]: −1 + 0.75 × 2 = 0.5.

17.3 · Z-score (zero-mean) normalization

Idea: har value ko batao ki wo mean se kitne standard deviation door hai. + matlab average se upar, − matlab neeche, 0 matlab bilkul average.

z = (v − μ) / σ
Notation / matlab — z, v, μ, σ
  • v = original value. n = values ki ginti.
  • μ (mu) = mean = average = (sab values ka sum)/n.
  • σ (sigma) = standard deviation (SD) = √(Σ(v − μ)² / n) — values mean se kitni “door-door” hain. Yahan population SD (n se divide); sample SD n−1 se divide karta hai.
  • z = z-score = “v, mean se kitne SD door hai”. Example: μ = 5, σ = 2, v = 9 → z = (9 − 5)/2 = 2 → 9, mean se 2 SD upar.

Worked example — data {2, 4, 4, 4, 5, 5, 7, 9}

  1. Mean: μ = (2+4+4+4+5+5+7+9)/8 = 40/8 = 5.
  2. Deviations (v−μ): −3, −1, −1, −1, 0, 0, 2, 4. Squares: 9, 1, 1, 1, 0, 0, 4, 16, sum = 32.
  3. Population variance σ² = 32/8 = 4, σ = 2. (Sample SD s = √(32/7) = 2.138 hota agar n−1 se divide karte.)
  4. z = (v−5)/2:

Z-score se fair tulna

Maths: Rahul 70 (class mean 60, SD 10) → z = +1.0. Physics: Aman 65 (class mean 50, SD 5) → z = +3.0. Raw marks mein Rahul aage dikhta hai, par apni class ke hisaab se Aman kaafi zyada upar hai. Z-score "relative position" batata hai.

Z-score ki properties

  • Naye data ka mean = 0, SD = 1; shape (distribution ka aakaar) same rehta hai.
  • Bounded nahi hai (+3, −4 sab possible). Normal-ish data mein ~99.7% values −3 se +3 ke beech.
  • Outlier ko dabata nahi, par min-max jitna damage bhi nahi karta (mean/SD bhi outlier se thoda hilte hain).
  • Inverse: v = μ + z·σ. Jaise μ = 50, σ = 8, z = −1.25 → v = 50 − 10 = 40.
  • σ = 0 (saari values same) → z undefined.
Population SD vs Sample SD

Agar sawal mein mean aur standard deviation diye hue hain (GATE 2024 Q27 jaisa), to seedha use karo; apne aap n ya n−1 ka jhanjhat nahi. Agar data dekar SD "calculate karo" bola ho, to jo convention sawal likhe (population: ÷n, sample: ÷(n−1)) wo lagao. Example {10,20,30}: population σ = √(200/3) = 8.165 → z = −1.225, 0, +1.225; sample s = 10 → z = −1, 0, +1.

17.4 · Decimal scaling

Notation: v = original value, v' = naya, j = ek poora number (1, 2, 3...) jo batata hai 10 ki kaunsi power (10j = 10, 100, 1000...) se divide karna hai, |v| = v ki absolute value (minus hata ke).

Har value ko 10 ki power se divide karo jab tak sabse badi absolute value 1 se chhoti ho jaye:

v' = v / 10j   (j = sabse chhota integer jisse max |v'| < 1)
  1. Data {−991, 45, 986}: max |v| = 991.
  2. j = 3 chuno: 991/10³ = 0.991 < 1 ✔ (j = 2 se 9.91 > 1 ✘).
  3. Result: −0.991, 0.045, 0.986.
j ka trap

Max |v| = 1000 ho to j = 3 galat hai (1000/1000 = 1, jo "< 1" nahi). Sahi j = 4 → 0.1. Max = 100 → j = 3 (0.1), max = 99 → j = 2 (0.99). Strictly less than 1 yaad rakho.

Teeno methods ek hi data par — {20, 40, 60, 80, 100}

μ = 60, σ = √((1600 + 400 + 0 + 400 + 1600)/5) = √800 = 28.284.

Ye table kaise bani (har column ka rule):

  1. Data {20, 40, 60, 80, 100}: min = 20, max = 100, range = 80; μ = (20+40+60+80+100)/5 = 300/5 = 60.
  2. Deviations v − μ = −40, −20, 0, 20, 40; squares 1600, 400, 0, 400, 1600, sum 4000; σ = √(4000/5) = √800 = 28.284.
  3. Min-max column: (v − 20)/80. Jaise v = 40: 20/80 = 0.25.
  4. Z-score column: (v − 60)/28.284. Jaise v = 40: −20/28.284 = −0.707.
  5. Decimal scaling column: max |v| = 100; j = 3 kyunki 100/10³ = 0.1 < 1 (j = 2 se 100/100 = 1, jo “< 1” nahi). Har v ko 1000 se divide: 40/1000 = 0.04.

17.5 · PYQ — GATE DA 2024, Q27 z-score normalization (1 mark, MCQ)

Question (paper se, faithfully)

Let the minimum, maximum, mean and standard deviation values for the attribute income of data scientists be ₹46000, ₹170000, ₹96000, and ₹21000, respectively. The z-score normalized income value of ₹106000 is closest to which ONE of the following options?

(A) 0.217    (B) 0.476    (C) 0.623    (D) 2.304

  1. Kaun sa formula? "z-score" pucha hai, to z = (v − μ)/σ. Min = 46000 aur max = 170000 min-max ke liye hote hain — yahan distractor hain.
  2. Values daalo: v = 106000, μ = 96000, σ = 21000.
  3. Numerator: 106000 − 96000 = 10000.
  4. z = 10000 / 21000 = 10/21 = 0.47619… ≈ 0.476.

Figure 17.1 · Income 1,06,000 mean se 10,000 upar hai, yaani 10,000/21,000 ≈ 0.476 SD upar.

Answer: (B) 0.476 (derived)

Official answer key paper PDF mein nahi hai, isliye ye hamara derived answer hai: 10000/21000 = 0.47619; check: 21000 × 0.476 = 9996 ≈ 10000 ✔.

Baaki options kahan se aaye?
  • (A) 0.217: ye 10000/46000 = 0.2174 hai — yaani SD ki jagah min (46000) se divide kar diya. Typical galti.
  • Min-max se (jo sawal ne nahi pucha): (106000−46000)/(170000−46000) = 60000/124000 = 0.4839 — ye bhi koi option nahi hai, aur sawal ne maanga bhi nahi. Min/max sirf distractor hain.
  • (C), (D): distractors.

Paper: GATE DA 2024, Q.27 — 1 mark, MCQ (4 options, ek sahi).

17.6 · Discretization — numbers ko bins mein todna

Real-life picture

Marks 0-100 hain par result "Distinction / First / Second / Fail" banta hai. 83 aur 85 dono "Distinction" — exact value ki jagah bin ka label. Fayde: data chhota, noise kam, rules (decision trees, association rules) simple, aur kuch algorithms sirf categorical data lete hain.

Isi ko concept hierarchy bhi banata hai: age → {young, middle-aged, senior} → all (Lesson 20 mein warehouse hierarchies).

Continuous values
→cut points
Bins / intervals
→label
young / adult / senior

Binning (unsupervised): do tareeke

Equal-width (equal-interval)

Range ko barabar chaudai ke bins mein baanto.

Notation: k = kitne bins chahiye, w = har bin ki chaudai (width), ⌊ ⌋ = floor (neeche ka poora number; ⌊1.1⌋ = 1, ⌊2.0⌋ = 2).

Width w = (max − min)/k

Bin boundaries: min, min+w, min+2w, ... , max. Value v ka bin number = ⌊(v − min)/w⌋ (max wali value ko last bin mein daalte hain).

Plus: simple. Minus: skewed data mein ek bin bhar jata hai, kuch khali.

Equal-frequency (equal-depth)

Sorted data ko barabar count ke bins mein baanto. N values, k bins → har bin mein ≈ N/k values.

Bins ki chaudai alag-alag hoti hai. Plus: har bin mein data milta hai. Minus: ek hi value ke duplicates alag bins mein jaa sakte hain (convention follow karo).

N, k se divide na ho to pehle kuch bins mein 1 zyada (jaise 10 values, 3 bins → 4, 3, 3).

Worked example — prices (sorted): 4, 8, 15, 21, 21, 24, 25, 28, 34   (N = 9, k = 3)

Figure 17.2 · Wahi 9 values, do alag binning

(a) Equal-width: w = (34 − 4)/3 = 10

  1. Bins: [4,14), [14,24), [24,34] (last bin mein 34 bhi shaamil). Index = ⌊(v−4)/10⌋: v = 15 → ⌊1.1⌋ = 1 (bin 2); v = 24 → ⌊2.0⌋ = 2 (bin 3); v = 34 → ⌊3.0⌋ = 3, par k = 3 hi bins hain, to last bin (index 2) mein.
  2. Bin 1: {4, 8} · Bin 2: {15, 21, 21} · Bin 3: {24, 25, 28, 34}. Sizes 2, 3, 4 — barabar nahi.

(b) Equal-frequency: 9/3 = 3 per bin

Bin 1: {4, 8, 15} · Bin 2: {21, 21, 24} · Bin 3: {25, 28, 34}.

Smoothing by bins (noise hatana) — equal-frequency bins par

Yahan bin ka label nahi, balki har value ko bin ke "representative" se replace karte hain:

Smoothing — 3 tareeke

Original4, 8, 1521, 21, 2425, 28, 34
By bin means9, 9, 922, 22, 2229, 29, 29

  1. Means: (4+8+15)/3 = 27/3 = 9; (21+21+24)/3 = 66/3 = 22; (25+28+34)/3 = 87/3 = 29.
  2. Boundaries: har bin ke min aur max "boundary" hain. Beech wali value ko nazdeeki boundary se replace karo. Bin 1: 8 → |8−4| = 4, |15−8| = 7 → 4. Bin 2: 21 → 21 (min), 24 → 24 (max). Bin 3: 28 → |28−25| = 3, |34−28| = 6 → 25.
Smoothing traps
  • Boundary smoothing mein bin ka min aur max badalte nahi; sirf beech wali values boundary par jaati hain.
  • Tie ho (beech wali value dono boundary se barabar door) to sawal ki convention; GATE aksar tie nahi banata.
  • Boundaries smoothing mein "boundary" = bin ke andar ki actual values ka min aur max (jaise equal-width Bin 3 mein 24 aur 34), interval ke edges (14, 24) nahi.

Skewed data par dono ka fark — {1, 2, 3, 4, 5, 6, 7, 8, 100}, k = 3

Yaad rakho
  • Outliers / skew → equal-frequency behtar.
  • Uniform data aur interpretable cut points (0-20, 20-40) → equal-width.
  • Dono unsupervised hain (class label nahi dekhte).
Ab tum try karo

Q. Data 12, 15, 18, 21, 24, 27, 30, 33, 36 ko 3 equal-frequency bins mein baanto aur bin-means se smooth karo.

Answer: {12,15,18} → 15; {21,24,27} → 24; {30,33,36} → 33. Smoothed: 15,15,15, 24,24,24, 33,33,33.

17.7 · Discretization ke aur tareeke kam important — sirf naam

kam important — sirf naam-level

Syllabus mein discretization ka matlab mukhya taur par binning hai (equal-width / equal-frequency + smoothing, upar padha). Baaki tareeke sirf naam se jaan lo: histogram analysis (histogram ke buckets hi bins), clustering (values ko clusters mein baanto, har cluster ek label), aur class-label wale supervised tareeke entropy-based split / ChiMerge. Inke formulas / worked examples GATE DA syllabus se bahar hain — Syllabus mein nahi — skip.

17.9 · Practice questions answers ke saath

Q1. Min = 10, max = 30. v = 20 ka [0,1] min-max?
✔ (20−10)/(30−10) = 10/20 = 0.5
Q2. Min = 5, max = 25. v = 15 ko [0,10] mein map karo.
✔ (15−5)/20 × 10 = 5
Q3. μ = 100, σ = 20. v = 90 ka z-score?
✔ (90−100)/20 = −0.5
Q4. μ = 50, σ = 8, z = −1.25. Original v?
✔ v = 50 + (−1.25)(8) = 40
Q5. Data {−780, 45, 912} ko decimal scaling se normalize karo.
✔ Max |v| = 912 → j = 3: −0.78, 0.045, 0.912
Q6. Max |v| = 1000 ho to decimal scaling mein j?
✔ j = 4, kyunki 1000/10³ = 1 hai jo "1 se chhota" nahi hai. Tab 1000 → 0.1.
Q7. Range [0,60], 3 equal-width bins. Width? v = 40 kis bin mein?
✔ w = 20. Bins [0,20), [20,40), [40,60]. v = 40 → ⌊40/20⌋ = 2, yaani third bin [40,60].
Q8. Data 3,5,7,9,11,13 ka min-max [0,1]?
✔ Range 10: 0, 0.2, 0.4, 0.6, 0.8, 1.
Q9. Bin {2, 5, 7, 10} ko boundaries se smooth karo.
✔ 5: |5−2| = 3 vs |10−5| = 5 → 2. 7: |7−2| = 5 vs |10−7| = 3 → 10. Result {2, 2, 10, 10}.
Q10. Data {5, 5, 5} par min-max ya z-score?
✔ Dono undefined: min-max mein max − min = 0; z-score mein σ = 0. Special handling (e.g. 0 assign) chahiye.
Q11. Training range [0,100] se min-max fit kiya. Test value 120 ka normalized value?
✔ 120/100 = 1.2 — [0,1] ke bahar. Min-max naye data par out-of-range de sakta hai.
Q12. z-score normalization ke baad data ka mean aur variance?
✔ Mean 0, variance 1 (SD 1).
Q13. Data {10, 20, 30}: population σ se z-scores?
✔ μ = 20, σ² = 200/3, σ = 8.165: −1.225, 0, +1.225. (Sample s = 10 hota to −1, 0, 1.)
Q14. MSQ — sahi statements: (a) min-max order preserve karta hai. (b) z-score output hamesha [−1,1] mein. (c) equal-frequency binning mein har bin ki width barabar. (d) equal-width bins mein bin counts alag ho sakte hain.
✔ (a) aur (d). (b) galat (unbounded), (c) galat (count barabar, width nahi).
Q15. Equal-frequency 3 bins mein 10 sorted values: sizes?
✔ 4, 3, 3 (convention: extra value pehle bin(s) mein; sawal ki convention follow karo).
Q16. Data 5, 10, 15, ..., 50 (10 values) ko 5 equal-width bins mein baanto. Width aur counts?
✔ w = (50−5)/5 = 9. Bins [5,14), [14,23), [23,32), [32,41), [41,50]: {5,10}, {15,20}, {25,30}, {35,40}, {45,50} → har bin mein 2 values.
Q17. Age range 20–60, income range 20,000–1,00,000. A = (30, 40000), B = (50, 80000). Dono ko min-max [0,1] karke Euclidean distance nikalo.
✔ A = (10/40, 20000/80000) = (0.25, 0.25); B = (30/40, 60000/80000) = (0.75, 0.75). d = √(0.5² + 0.5²) = √0.5 = 0.707.
