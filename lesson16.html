Data types — data ka nature samjho
Nominal · Ordinal · Interval · Ratio · Discrete/Continuous · Binary · SQL types

16.1 · Type kyun matter karta hai? sahi type = sahi operations

Real-life picture

Tumhare phone ke contacts mein ek column hai Phone number (9876543210) aur ek column hai Age (21). Dono "number" jaise dikhte hain. Kya tum do logon ke phone numbers ka average nikaloge? Bekaar hai. Age ka average? Bilkul useful. Matlab sirf "number jaisa dikhna" kaafi nahi: value ka nature (type) decide karta hai ki kaun si operations sensible hain.

Is lesson ka ek-line summary

Data ke 2 type-systems hote hain: (1) DB/programming type (INT, VARCHAR, DATE ... computer kaise store kare) aur (2) statistical/measurement type (Nominal, Ordinal, Interval, Ratio ... kaun si maths valid hai). GATE DA dono se sawal pooch sakta hai. Dono ko alag rakho, phir jodo.

16.2 · Statistical (measurement) types ka poora naksha

Figure 16.1 · Attribute types ka tree. Discrete/Continuous ek alag axis hai jo numeric attributes par lagta hai.

Chaar scales — NOIR yaad rakho (Nominal, Ordinal, Interval, Ratio)

Har agla scale pichhle scale ki saari powers rakhta hai plus ek nayi power. Ek seedhi ladder socho:

NOMINAL
sirf = ≠ (same / different)
→+ order
ORDINAL
+ < > (kaun bada)
→+ equal gap
INTERVAL
+ − (kitna zyada)
→+ true zero
RATIO
+ × ÷ (kitne guna)

1. Nominal — sirf naam / label

Values sirf naam hain; koi order ya distance nahi. Examples: blood group (A, B, O, AB), department (CSE, ECE), city, colour, roll number, pin code, phone number, jersey number.

  • Valid: equal / not equal check, count, mode (sabse common value), frequency table.
  • Invalid: "A < B", average, difference. Blood group B > A koi matlab nahi rakhta.

2. Ordinal — order hai, par gap barabar nahi

Values ko rank kar sakte ho (chhota-bada), lekin do values ke beech ka distance fix/meaningful nahi. Examples: Low/Medium/High, grade A/B/C/D, shirt size S/M/L/XL, star rating 1-5, class rank, education level (10th < 12th < UG < PG).

  • Valid: nominal wali sab + < > compare, median, percentile, rank correlation.
  • Invalid (strictly): mean aur difference. Race mein 1st aur 2nd ke beech 0.1 sec ho sakta hai, 2nd aur 3rd ke beech 5 sec; rank 1,2,3 "barabar gap" dikhate hain par asli gap barabar nahi.

3. Interval — gap barabar, par zero "asli" nahi

Do values ka difference meaningful hai (20°C aur 30°C ka gap = 30°C aur 40°C ka gap). Lekin zero ek convention hai, "kuch nahi" nahi. Examples: temperature in Celsius / Fahrenheit, calendar year (2000, 2024), calendar date, IQ score, clock time of day.

  • Valid: ordinal wali sab + + , −, mean, standard deviation, correlation.
  • Invalid: ratio ("2 guna garam"). 20°C ka matlab "10°C ka double" nahi hai. Dekho: 10°C = 50°F aur 20°C = 68°F: Celsius mein ratio 2, Fahrenheit mein ratio 68/50 = 1.36. Ek hi physical cheez, do ratios — matlab ratio ka koi meaning nahi. Kelvin mein: 283.15 K aur 293.15 K, ratio = 1.035 (kyunki Kelvin ka 0 asli zero hai).

4. Ratio — sab kuch valid, true zero ke saath

Zero ka matlab "bilkul kuch nahi". Examples: age, height, weight, salary, price, Kelvin temperature, distance, number of items (count), time duration, bank balance.

  • Valid: sab kuch: + − × ÷, mean, SD, geometric mean, coefficient of variation, "kitne guna".
  • Example: Rs 100 aur Rs 200 — "doguna" bilkul meaningful hai, kyunki Rs 0 = paisa hi nahi.
Interval vs Ratio — ek sawal se pakdo

"Kya zero ka matlab absence (kuch nahi) hai?" Haan → Ratio. Nahi → Interval. 0 kg = koi vazan nahi (ratio). 0°C = paani ka freezing point, garmi ka absence nahi (interval). Year 0 = koi "time ka start" nahi (interval).

Permissible transformations (kaun sa badlaav scale ko nahi todta)

Ek scale tab tak "wohi scale" hai jab tak tum values ko aise function se badlo jo uska meaning preserve kare. Isse hi GATE ka "kaunsa scale hai" sawal solve hota hai.

Yaad rakhne ka jugaad

Nominal = Name · Ordinal = Order · Interval = Interval (gap) · Ratio = Ratio. French mein NOIR = black. Aur arithmetic ki ladder: = → < → − → ÷.

Ab tum try karo

Q. Temperature −5°C ko 5°C se compare karke bol sakte ho ki "5°C 5 guna garam"? Kaun sa scale?

Answer: Nahi. Celsius interval hai, ratio meaningful nahi (aur −5 se ratio to negative ho jata hai).

16.3 · Binary attributes — symmetric vs asymmetric

Binary = sirf do possible values (0/1, Yes/No, True/False). Ye nominal ka ek special case hai (do hi labels). Par GATE/data-mining mein iske do flavours alag treat hote hain:

Symmetric binaryAsymmetric binary
MatlabDono outcomes barabar importantEk outcome zyada important / rare (usually 1 = important, rare)
ExamplesGender (M/F), married (Y/N), left-handed/right-handedDisease test +ve/−ve, "student ne ye rare course liya?", fraud/not-fraud, bought-item-in-basket
CodingKoi bhi value 0/1 de sakte hoImportant/rare outcome ko 1 do, common ko 0
SimilaritySimple Matching (SMC): (f11 + f00) / nJaccard: f11 / (f11 + f10 + f01), (0-0 match ignore)

Worked example — similarity of two binary vectors

Do patients ke 10 symptoms/tests (1 = present):

Binary vectors
s1s2s3s4s5s6s7s8s9s10
p1010000100
q1000001100
  1. Count karo: f11 (dono 1) = s1, s8 = 2.
  2. f10 (p=1, q=0) = s3 = 1.   f01 (p=0, q=1) = s7 = 1.
  3. f00 (dono 0) = 10 − 2 − 1 − 1 = 6.
  4. SMC = (f11 + f00)/n = (2 + 6)/10 = 0.8.
  5. Jaccard = f11/(f11+f10+f01) = 2/(2+1+1) = 0.5.
Kyun do formulas?

Zyada-tar patients mein zyada-tar symptoms absent (0) hote hain. Agar 0-0 match ko "similar" gino to koi bhi do healthy log "bahut similar" dikhenge (SMC bada). Asymmetric attribute mein 0-0 ka koi information nahi, isliye Jaccard sirf 1 wale matches dekhta hai.

16.4 · Discrete vs Continuous (numeric ka dusra axis)

Discrete

Countable values; do values ke beech "gap" hota hai. Number of students (0,1,2..), number of purchases, bugs count, dice outcome. Finite ya countably infinite (0,1,2,3,...) dono discrete.

Continuous

Range mein koi bhi real value (do values ke beech aur values mil jaati hain): height, weight, time, temperature, salary (theoretical). Instrument/computer mein finite precision se store hoti hai, par nature continuous mana jata hai.

  • Binary / nominal / ordinal hamesha discrete hote hain (finite labels).
  • Discrete + ratio ka example: count (number of children). Continuous + ratio: weight. Continuous + interval: temperature in °C.
  • Trap: Age. Nature se continuous (ratio); agar sirf "completed years" integer likho to recorded form discrete dikhta hai. Sawal mein jo likha ho wohi follow karo; GATE aksar "age = ratio, numeric" bolta hai.

GATE trap #1: number dikhna = numeric nahi

Roll number, pin code, phone number, Aadhaar, jersey number numbers se likhe jaate hain par identifier (nominal) hain. Inka sum/average meaningless hai aur DB mein inhe CHAR/VARCHAR mein rakhna better hota hai (leading zero 0123 na ud jaye).

GATE trap #2: Likert / rating scales

1-5 satisfaction rating strictly ordinal hai. Practically log mean nikaal lete hain (interval maan kar), par theoretically gap barabar guarantee nahi. Exam mein: "order hai, gap equal nahi" likha ho to ordinal.

Cheez-by-cheez

DECIMAL(p, s) range

Digits before point = p − s. Max value = 10(p−s) − 10−s.

  • DECIMAL(7,2): 5 digits before point → range ±99,999.99
  • DECIMAL(5,2): ±999.99 (1000.00 overflow ho jayega)
  • DECIMAL(6,3): ±999.999
FLOAT vs DECIMAL

FLOAT binary fractions use karta hai: 0.1 + 0.2 = 0.30000000000000004 (double precision). Isliye paisa/money = DECIMAL, scientific measurements = FLOAT.

CHAR(n) vs VARCHAR(n)

Value 'IN' ko CHAR(10) mein store karo to 10 characters (8 blank padding) space leta hai. VARCHAR(10) mein sirf 2 characters + chhota length-prefix (1-2 byte). Isliye variable-length data (naam, address) ke liye VARCHAR; hamesha-same-length data (country code, PAN-like fixed codes) ke liye CHAR. Padding/comparison ke exact rules DBMS par depend karte hain — sawal mein jo dialect/context ho wohi follow karo.

Type ka effect — ek example

CREATE TABLE Employee (
  EmpID    INT PRIMARY KEY,        -- identifier but stored as integer
  Name     VARCHAR(40),            -- nominal
  Dept     CHAR(3),                -- nominal, fixed length (CSE, ECE)
  Grade    CHAR(1),                -- ordinal (A,B,C)
  Salary   DECIMAL(9,2),           -- ratio, exact money
  JoinDate DATE,                   -- interval
  IsActive BOOLEAN                 -- binary
);
Mapping yaad rakho

DB type ≠ statistical type. INT column ke andar roll number (nominal) bhi ho sakta hai aur quantity (ratio) bhi. Type decide karne ke liye values ka meaning dekho, column ka SQL type nahi. SQL type sirf yeh batata hai ki kaun si operation DBMS allow karega (SUM on VARCHAR error), jabki statistical type batata hai ki kaun si operation meaningful hai.

Date / time, text aur NULL

  • Date: do dates ka difference (days) ratio hai; date khud interval hai ("2024 = 2 × 1012" bekaar).
  • Text / free-form string: unstructured; analysis ke liye pehle tokens/categories banate hain (data transformation).
  • NULL: "unknown / not applicable" — type ka hissa nahi, har domain mein ek extra "missing" status. NULL ke saath comparison hamesha UNKNOWN deta hai.
Quick revision — 5 lines
  • Categorical: Nominal, Ordinal, Binary. Numeric: Interval, Ratio.
  • Nominal: = ≠ , mode. Ordinal: + < >, median. Interval: + −, mean. Ratio: + × ÷.
  • Zero asli? Haan = ratio, nahi = interval.
  • Discrete = gin sakte ho; Continuous = range ki koi bhi value.
  • Binary asymmetric (rare outcome = 1) → Jaccard.

16.7 · GATE-style problems PYQ status + practice

PYQ status (GATE DA 2024, 2025, 2026 papers check kiye)

In teeno papers mein "nominal/ordinal/interval/ratio" ya SQL data-type par koi seedha question nahi aaya. Syllabus mein "data types" hai isliye 1-2 mark ka conceptual MCQ/MSQ kabhi bhi aa sakta hai. Neeche practice set exam-style hai.

Practice questions (answers ke saath)

Q1. Blood group (A, B, AB, O) kaun sa scale hai? Median nikaal sakte hain?
✔ Nominal. Median nahi (order nahi). Sirf mode.
Q2. Shirt size S, M, L, XL — scale? Valid central measure?
✔ Ordinal. Median/mode valid; mean strictly valid nahi.
Q3. Temperature in Kelvin kaun sa scale? Kyun?
✔ Ratio. 0 K = absolute zero (molecular motion nahi) = true zero; 200 K sach mein 100 K ka double hai.
Q4. Calendar year (1990, 2020) ke liye "2020, 1990 ka 1.01 guna" meaningful hai?
✔ Nahi. Year interval scale hai; zero (year 0) arbitrary. Difference (30 saal) meaningful hai.
Q5. "Number of siblings" ka type?
✔ Ratio, discrete (count; 0 = koi nahi).
Q6. Pin code 110001 ka average kyun meaningless? Type?
✔ Nominal identifier. Number sirf label hai, arithmetic ka koi matlab nahi. VARCHAR mein store.
Q7. Disease test (positive/negative) — binary symmetric ya asymmetric? Similarity measure?
✔ Asymmetric (positive rare + important). Jaccard (1-1 matches).
Q8. p = (1,1,0,0,1,0), q = (1,0,0,0,1,1). SMC aur Jaccard?
✔ f11 = 2 (pos 1,5), f10 = 1 (pos 2), f01 = 1 (pos 6), f00 = 2. SMC = (2+2)/6 = 4/6 = 0.667. Jaccard = 2/(2+1+1) = 0.5.
Q9. DECIMAL(6,3) mein sabse bada positive value?
✔ 999.999 (6 − 3 = 3 digits before point).
Q10. °C → °F (F = 1.8C + 32) interval scale ko preserve karta hai ya ratio ko?
✔ Interval ko (linear a·x + b), ratio ko nahi (b ≠ 0). 10°C → 50°F, 20°C → 68°F: ratio 2 se 1.36 ho gaya.
Q11. MSQ: Kaun se statement sahi hain? (a) Ordinal scale par median valid. (b) Interval par ratios meaningful. (c) Ratio scale par sab arithmetic valid. (d) Nominal par mean valid.
✔ (a) aur (c). (b) galat (zero artificial), (d) galat (order tak nahi).
Q12. Paisa store karne ke liye FLOAT ya DECIMAL(10,2)?
✔ DECIMAL(10,2): exact arithmetic; FLOAT approximation errors (0.1 + 0.2 ≠ 0.3) deta hai.
Q13. Ek attribute "Grade: A, B, C, D, F" ko hum 4,3,2,1,0 code karte hain. GPA average nikalna theoretically kyun risky?
✔ Grade ordinal hai; codes 4..0 ke beech gap barabar guarantee nahi (A aur B ke beech gap = B aur C ke beech gap?). Mean interval maanta hai.
Q14. Ek sensor reading "temperature in Celsius, 2 decimals". Discrete ya continuous? Scale?
✔ Continuous (measured on range), interval scale (zero artificial).
